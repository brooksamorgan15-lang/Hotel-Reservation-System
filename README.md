# Hotel Reservation System

## Overview
A Python-based hotel reservation system that allows users to create, edit, delete, save, and load reservations while managing room availability.

## Features
- Create reservations
- View reservations
- Edit reservations
- Delete reservations
- Save reservation data
- Load existing reservations
- Automatic room management

## Technologies Used
- Python
- Object-Oriented Programming

## Skills Demonstrated
- Data validation
- File handling
- Functions
- Problem solving
- User interaction

## Future Improvements
- Graphical user interface (GUI)
- Database integration (SQLite)
- User authentication
